# Lazy Monster Builder 1.0.0

Updates the module for Foundry Virtual Tabletop v14 and D&D 5e 6.0.6.

- Adds the generator to the v14 Actors directory and uses DialogV2.
- Generates native attack, damage, utility, and saving throw activities.
- Retains the resource tables, custom proficiency, tokens, and feature descriptions.
- Uses v14 Active Effects for proficiency and energy damage bonuses.
- Creates the actor and its embedded documents together, then reports success.
- Publishes a complete Foundry package with stable installation and update URLs.

Required original credits are retained in ATTRIBUTION.md.
